# Every file under usr/lib of the AppDir the AppImage is written from,
# one path per line, relative to usr/lib, sorted as LC_ALL=C sort does.
# rewrite_appimage in reproducible/targets/linux.sh compares the AppDir
# with this list once the Wayland libraries are out, and stops the build
# on one file more or one less. The comment lines and blank lines of
# this header are not part of the list; keep comments here, the list a
# failed build writes into build-info starts again from this header.
#
# Why a list: AppRun puts usr/lib first on LD_LIBRARY_PATH, so a library
# here is loaded in place of the system's, by Gerfaut and by every
# GStreamer plugin, GTK module and helper process it starts. A new apt
# image or a new linuxdeploy can bring one no one asked for, as a
# GStreamer plugin once brought OpenSSL 3.0, and nothing else would
# notice it.
#
# Where the files come from:
#   at the top          the libraries of the image that linuxdeploy found
#                       the binary, WebKit's helpers and the modules
#                       below to need, less the Wayland ones, and a copy
#                       of the GTK and gdk-pixbuf modules it deployed
#   gstreamer-1.0/      the GStreamer plugins (gstreamer_plugins)
#   gstreamer1.0/       GStreamer's plugin scanner and PTP helper
#   gtk-3.0/, gdk-pixbuf-2.0/, gio/
#                       the GTK input and print modules, the image
#                       loaders and the GIO modules that the gtk plugin
#                       copies, with their caches
#   girepository-1.0/   the typelibs the gtk plugin copies
#   x86_64-linux-gnu/   WebKit's helper processes and injected bundle
#
# When the build stops on a difference, it shows the diff and writes the
# list as it found it, this header kept, to build-info/appimage-libs.txt
# of its output. Find what brought each new line or took one away, then
# copy that file over this one, in a commit of its own.
